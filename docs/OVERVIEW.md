# HICEL Specification Overview

This repository defines HICEL as a **portable representation grammar**.
HICEL is not a world; it is the set of conventions by which worlds are represented such that HIPF-style evaluation can be applied.

## Core commitments

- Content-agnostic primitives
- Deterministic schemas for tools (YAML/JSON where appropriate)
- Layer separation (diegetic content vs analytical constraints)
- Patch/diff-friendly authoring
- Explicit external authority references (HIPF anchors and other authorities)

## Non-goals

HICEL does not define metaphysics, cosmology, theology, species metaphysics, or canonical world semantics.
