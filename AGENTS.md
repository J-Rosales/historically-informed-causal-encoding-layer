# AGENTS

## Project overview
This repository documents the Historically-Informed Causal Encoding Layer (HICEL) specifications.
Most changes update Markdown documentation, templates, and schema placeholders.

## Working guidelines
- Keep documentation consistent with the docs in `docs/` and templates in `templates/`.
- Prefer concise, descriptive headings and bullet lists.
- If you add new docs, update `docs/REPO_STRUCTURE.md` as needed.

## Testing
No automated tests are defined for this repository.
